# Codex-theme-Aemeath · 小爱的星海

<img src="assets/aemeath.webp" alt="爱弥斯主题设置入口" width="140" align="right"/>

给 Windows 上的 Codex 加上小爱主题：浅粉与深粉紫配色、文件夹壁纸轮播、玻璃卡片，以及会呼吸的输入框星光。

这是非官方主题。保留 Codex 的原生输入、发送、项目和会话导航，在项目内生成一个主题运行副本，官方安装目录保持不变。

## 功能

- 浅粉、深粉紫分别记住背景文件夹、轮播、透明度、模糊与星光参数。
- 自选文件夹轮播 PNG、JPEG、WebP、GIF；默认不附带背景，单图上限 32 MiB。
- 首页四个可固定项目入口，各列可滚动查看会话；欢迎卡切换项目并同步输入框。
- 侧边栏、卡片和输入框的玻璃效果可调，不透明度最低 0%。
- 星光支持呼吸或固定亮度；呼吸动画仅更新输入框装饰层。
- 右下角小爱按钮可调大小，打开设置或退出主题。

## 安装

先安装并打开一次官方 Codex。准备 Node.js 22 或更高版本、Python 3.10 或更高版本；`node`、`npm`、`python` 需可在终端运行。

下载本仓库 ZIP 并解压，或执行：

```powershell
git clone https://github.com/WhaleLee1996/Codex-theme-Aemeath.git
cd Codex-theme-Aemeath
npm ci
npm run build
python -B scripts/setup.py
```

首次安装默认使用**项目内的独立资料**，需要单独登录、添加项目。安装完成后，保存草稿并完全退出其他 Codex 窗口，再打开生成的 `小爱 Codex（日常）.lnk`。安装脚本不会自动启动应用。

如希望使用自己原来的账号、项目和聊天，先明确选择原资料模式，再使用生成的日常快捷方式：

```powershell
python -B scripts/setup.py --profile original
```

此模式会正常读写你自己的原 Codex 资料目录。脚本仅验证和引用现有目录，不复制登录凭据或聊天；如果找不到资料目录会停止，不创建空目录冒充原资料。

首次进入后，点右下角小爱 → 背景 → 选择文件夹。浅粉与深粉紫各自选择，可以指向同一个文件夹。增删图片后会自动刷新，只扫描目录第一层。

## 启动、退出和移动

- `小爱 Codex（日常）.lnk`：使用安装时选择的资料模式。
- `小爱 Codex（试验）.lnk`：始终使用项目内独立资料。
- `Codex（原生外观）.lnk`：使用选定资料，跳过主题加载。
- 设置中的“退出主题”可当场恢复原生外观；完全退出后使用官方入口可回到官方程序。

请通过这些入口启动，不要直接运行 `runtime` 中的 EXE。启动器检查版本和实例占用，启动后退出，没有额外常驻主题窗口。

要移动或改名，先完全退出 Codex，再移动整个项目。之后运行 `修复启动入口.cmd` 重建项目内快捷方式；复制到桌面或固定到任务栏的入口需要重新复制／固定。项目外的图片目录仍保持原位置。

## 本地数据与恢复

运行时产生的 `data/`、`profiles/`、`runtime/`、`diagnostics/`、`logs/`、`exports/` 和背景文件夹均被 Git 忽略。本仓库不包含维护者的个人参数、项目列表、聊天、背景图片或 Codex 程序。

主题会修改本地副本的资源包，并同步副本 EXE 的资源摘要；它不会修改官方安装或关闭运行时资源完整性检查。重新打包的副本不保留原发布者签名。停用本项目时先退出主题副本，继续使用官方 Codex；需要保留的独立资料或自选图片请自行备份。

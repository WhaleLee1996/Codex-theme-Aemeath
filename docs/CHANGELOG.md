# 更新记录

## 0.1.19 · 2026-11-14

- 修复输入框底部的浅色白条与深色黑条。新版原生底栏使用伪元素绘制额外渐变与实色背景，本版只移除这些装饰，保留输入框玻璃、星光、尺寸和操作按钮。
- 同时适用于主聊天和侧边聊天；原生输入框移动、侧边聊天隐藏或主题停用时，正确清理并恢复相关样式。
- 默认应用版本仍为 `26.1111.21308`，适配表更新至 `26.1111.21308-r2`，新增六个原生样式分块的哈希校验。
- 新增底栏归属、未发送内容、选区、原生操作和恢复行为的回归测试。

分享版验证：96 项 JavaScript 测试、4 项 Python 安装配置测试及 16 个 JavaScript 模块语法检查通过。实现侧已使用实际原生 CSS 完成浅色／深色、主聊天／侧边聊天的独立渲染检查，并收到重启后的修复确认；这不代表其他电脑或未知应用版本已验收。

## 0.1.18 · 2026-11-14

本次从公开版 0.1.11 更新，汇总后续本地维护与布局调整。

- 默认适配 Windows Codex 内部版本 `26.1111.21308`（MSIX `26.1111.2228.0`）；保留历次版本适配表。
- 新版 Rspack 加载器复用原生已初始化服务，保留版本、哈希和打包完整性检查。
- 选中文字打开侧边聊天时，同时识别主输入框与侧边输入框；分别附加玻璃、星光和外沿效果，避免背景叠加与关闭侧栏后残留。
- 多输入框共用呼吸时钟，动画仅修改各自装饰层；原生编辑器、选区和发送逻辑保持原样。
- Chat 首页欢迎卡使用该页面自己的项目选择器，与 Work 的选择独立。
- Work 欢迎卡移至上方项目卡片下约 2 cm；矮窗口缩小间距，窄布局兼容两列项目卡片；Chat 布局保持不变。
- 分享构建与本机安装器校验相同的目标适配版本，继续保留主题独立参数、文件夹轮播和已有资料模式。

验证：94 项 JavaScript 测试与 4 项 Python 安装配置测试通过，16 个 JavaScript 模块通过语法检查。使用公开安装流程从本机受支持的官方应用生成了副本，核对 15 个构建文件及 2 个原生入口的语法；原生源文件、CSP 和运行时完整性开关保持不变。未由该检查启动应用，离线测试与打包核验不等同于不同电脑的原生视觉验收。
